# Compact lane brief

Adapt this to the lane; omit irrelevant fields. A brief can be a tool message rather than a new file.

```text
Role and bounded question:
Programme objective and why this question matters:
Minimal context, known evidence and supplied assumptions:
Working directory and selected files to read:
Owned files/output paths; shared files to leave alone:
Deliverable and evidence target:
Relevant method, data scope or frozen confirmatory criterion:
Resource/time limit, stopping condition and retry limit if relevant:
Existing authorization and limits; model mapping only if user-approved:
No recursive delegation unless explicitly assigned. Do not commit or publish
unless authorized. Respect the repository's instructions and other writers.

Return a concise handoff: central idea; findings and evidence status;
what follows from the common rule/design versus what was supplied;
strongest failure or uncertainty; recommended next question; artifact links.
```
